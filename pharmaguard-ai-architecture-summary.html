Module Descriptions

src/app.py Entry point

The Streamlit UI layer. Renders two tabs — Safety Signal Detector and Regulatory Submission Checker — and has no business logic of its own. Responsibilities:

  • File upload & input parsing (CSV, JSON)
  • Column / schema validation with actionable error messages
  • Delegating computation to safety_signal.py and ctd_checker.py
  • Requesting AI explanations from bob_adapter.py
  • Rendering metrics, tables, and AI summaries
src/safety_signal.py Core logic

Pure-Python PRR computation. No I/O, no UI imports — easily unit-testable. Key public API:

  • AdverseEventRecord — dataclass representing one reporting-dataset row
  • PRRResult — dataclass holding the four contingency cells, PRR value, and signal flag
  • compute_prr(records, prr_threshold, min_count) — aggregates counts, applies the Evans et al. (2001) formula, and returns results sorted by PRR descending

Signal threshold: PRR ≥ 2.0 and cell-a ≥ 3 co-reports (configurable). Division-by-zero (event exclusive to one drug) yields PRR = ∞ — still flagged when count criterion is met.

src/ctd_checker.py Core logic

Validates a dossier dictionary against the ICH Common Technical Document checklist (Modules 2–5). Key public API:

  • ICH_CTD_CHECKLIST — dict of 14 required section IDs → labels
  • SectionStatus — per-section readiness (present, non-empty, notes)
  • CTDReport — aggregated report with completeness_pct, missing_sections, is_submission_ready
  • check_dossier(dossier, checklist) — validates and returns a CTDReport

A section passes when its value is present (key exists) and truthy (non-empty string/dict/list). Accepts an optional custom checklist for jurisdiction-specific requirements.

src/bob_adapter.py AI layer

Thin wrapper around the IBM watsonx AI SDK (ibm-watsonx-ai). Isolates all AI-platform concerns so the core modules remain dependency-free. Key behaviours:

  • Attempts to import the SDK at module load; sets _SDK_AVAILABLE = False silently if absent
  • Reads WATSONX_API_KEY, WATSONX_PROJECT_ID, WATSONX_URL from environment variables
  • explain_signal(drug, event, prr) — calls IBM Granite to produce a plain-language clinical summary for a flagged signal
  • suggest_ctd_fix(section_id, label) — returns actionable ICH M4 guidance for a missing CTD section
  • Falls back to a static template string on any SDK, credential, or network error — the UI always has something to show

Design Principles

  • Separation of concerns — UI, computation, and AI are in separate modules with no circular imports.
  • Graceful degradation — the app runs fully offline; bob_adapter.py falls back to static text when the IBM SDK or credentials are unavailable.
  • Testability — safety_signal.py and ctd_checker.py have zero UI or network dependencies, making them trivially unit-testable.
  • Configurability — PRR threshold, minimum count, and CTD checklist are all runtime parameters, not hard-coded constants.
